# Run views — design reference

Committed reference for the runs board, run detail, and row anatomy
surfaces. The interactive canvas lives at
https://claude.ai/code/artifact/fd88ceda-d62c-4972-92f4-05add1f6a99b —
these are its artboard sources (neutral demo data). Implementation matches
these boards; deviations are deliberate and recorded in the PR that ships
them, not silent.
