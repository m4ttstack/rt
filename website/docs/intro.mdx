# rt

rt is the command line piece of **mattstack**, a suite of macOS developer tools for working in git worktrees, with AI agents alongside you. rt covers worktree navigation and lifecycle, safer git operations, service orchestration, port scanning, and the plumbing agents use to coordinate (chat, gates, runs, events).

## Part of mattstack

rt ships inside **mattstack.app**, the menu bar app that installs, updates, and supervises the whole suite. Every mattstack app shares rt's daemon and settings:

- [board](https://github.com/m4ttstack/board) for reviewing merge requests
- [gitq](https://github.com/m4ttstack/gitq) for stacked branches
- [deck](https://github.com/m4ttstack/deck) for local app hosting
- [fast-browser](https://github.com/m4ttstack/fast-browser) for driving your real Chrome
- [skills](https://github.com/m4ttstack/skills), the mattstack Claude Code plugins

## Mental model

Run `rt` with no arguments to get an interactive menu that walks you from repo, to worktree, to action. Every command also works as a direct invocation, so once you know the shape of a command you can skip the picker entirely:

```bash
rt <command> [subcommand] [args]
```

A background daemon runs alongside the CLI, caching MR and branch data, scanning ports, guarding git hooks, and snapshotting your home repo, so commands like `rt cd` and `rt port` stay fast and work from anywhere on your machine.

## Zero footprint

rt runs on Apple silicon Macs only. It keeps all of its state, config, and per-repo data under `~/.mattstack/` and never writes anything into the repos it manages, so onboarding a repo or uninstalling never touches your git history or working tree.

The Command reference section in the sidebar is generated from the same command tree that drives rt's interactive pickers, so it always matches what `rt` actually does. See [rt cd](/reference/cd) or [rt port](/reference/port) for examples of what a reference page looks like.
