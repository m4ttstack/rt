# rt settings migrate

`rt › settings › migrate`

Carry stored settings to each key's current store name; a dry run unless --write or --prune

## Usage

```bash
rt settings migrate [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--write` | boolean | `false` | Write each key's current store name from its migrated value where it is absent (additive) |
| `--prune` | boolean | `false` | Delete older store names labeled leftover or stale, after confirmation |
| `--team` | boolean | `false` | Let --prune touch the team store |
| `--force` | text |  | Let --prune delete this key's diverged older names (repeatable) |
| `--yes` | boolean | `false` | Confirm --prune without a prompt (non-interactive runs) |
| [`--json`](/guides/common-flags) | boolean | `false` | Machine-readable output |
