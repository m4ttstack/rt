# rt skills

`rt › skills`

Compile, check, and manage the surface of the pack's committed skills

## Usage

```bash
rt skills
```

## Subcommands

| Command | Description |
| --- | --- |
| [`link`](link) | Symlink a skills/*/SKILL.md tree into ~/.claude/skills by frontmatter name (create, repoint, prune; conflicts reported, never touched) |
| [`materialize`](materialize) | Run merge-manifests.sh to materialize skill bindings for registered repos |
| [`compile`](compile) | Compile pack verbs from step sources + manifest bindings into committed SKILL.md files |
| [`check`](check) | Report compiled skills that no longer match their sources |
| [`audit`](audit) | Advisory LLM audit of a pack's skills and fills for shell instructions the MCP tools cover (plain-words commands, shell-variable hand-offs, wrapped calls); slow, costs tokens, never a gate |
| [`sync`](sync) | Bring a pack's compiled skills and installed plugin caches current (recompile and plugin-update chain; refuses on content drift) |
| [`init`](init) | Scaffold this zone's team pack with a generic work pipeline, declare the repo, compile, check, and install it |
| [`surface`](surface) | List, set, or apply the pack's public/internal skill surface (bare invocation opens a multi-toggle palette) |
| [`packs`](packs) | List packs discovered from installed marketplace plugins that carry a surface.jsonc |
| [`composition`](composition) | Report the pack's full binding composition -- verbs, slots, fills, and every binder in the manifest (roster and stages both) |
| [`bind`](bind) | Write bindings.&lt;engineRef&gt;.&lt;slot&gt; = &lt;fill&gt; into the manifest (jsonc-parser, comments preserved) and, for a team pack, into the pack's pack/skills.jsonc fragment too, validate the fill against the slot's contract, and recompile (a stage bind recompiles the whole pack) |
| [`writing-style`](writing-style) | Show, list, choose, or start the voice for prose posted under your name |
