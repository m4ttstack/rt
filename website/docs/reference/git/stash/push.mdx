# rt git stash push

`rt › git › stash › push`

Stash tracked changes (optionally untracked too)

## Usage

```bash
rt git stash push [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--message` | text |  | Stash message |
| `--include-untracked` | boolean | `false` | Also stash untracked files |
| [`--json`](/guides/common-flags) | boolean | `false` | Machine-readable result |
