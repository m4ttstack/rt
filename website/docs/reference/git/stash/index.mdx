# rt git stash

`rt › git › stash`

Stash the working tree and manage stashes

## Usage

```bash
rt git stash
```

## Subcommands

| Command | Description |
| --- | --- |
| [`push`](push) | Stash tracked changes (optionally untracked too) |
| [`list`](list) | List stashes |
| [`pop`](pop) | Apply a stash and drop it (default stash@&#123;0&#125;) |
| [`apply`](apply) | Apply a stash, keeping it (default stash@&#123;0&#125;) |
| [`drop`](drop) | Delete a stash |
