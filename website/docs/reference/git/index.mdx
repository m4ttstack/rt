# rt git

`rt › git`

Git operations (status, diff, log, rebase, commit, stash, tags)

## Usage

```bash
rt git
```

## Subcommands

| Command | Description |
| --- | --- |
| [`rebase`](rebase) | Smart rebase onto origin/master with auto-resolve |
| [`reset`](reset) | Safe reset with divergence detection |
| [`commit`](commit) | Interactive staged/unstaged commit picker |
| [`backup`](backup) | Back up the current branch |
| [`restore`](restore) | Restore from a backup branch |
| [`pull`](pull) | Pull from origin (mirror of GitHub Desktop's Pull button) |
| [`push`](push) | Push current branch to origin/&lt;branch&gt;, fixing wrong upstream |
| [`upstream`](upstream) | Fix branch upstream to track origin/&lt;branch&gt; |
| [`status`](status) | Working tree status: branch, ahead/behind, changed files |
| [`diff`](diff) | One file's diff (hunks and lines) from git-core |
| [`log`](log) | Recent commits on the current branch |
| [`branches`](branches) | Local branches with upstream and ahead/behind state |
| [`amend`](amend) | Amend the last commit with what is staged (message optional) |
| [`undo`](undo) | Undo the last commit, keeping its changes in the working tree |
| [`stash`](stash) | Stash the working tree and manage stashes |
| [`tag`](tag) | Create, list, delete, and push tags |
