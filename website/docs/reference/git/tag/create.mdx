# rt git tag create

`rt › git › tag › create`

Create a tag (annotated when --message is given)

## Usage

```bash
rt git tag create <name> [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<name>` | text |  | Tag name |
| `--message` | text |  | Annotation message (makes the tag annotated) |
| `--at` | text |  | Commit to tag (default HEAD) |
| `--push` | boolean | `false` | Push the tag to origin after creating |
| [`--json`](/guides/common-flags) | boolean | `false` | Machine-readable result |
