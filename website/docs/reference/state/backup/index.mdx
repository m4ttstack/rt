# rt state backup

`rt › state › backup`

Write a stamped state.db backup (VACUUM INTO) and prune backups past retention

## Usage

```bash
rt state backup [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| [`--json`](/guides/common-flags) | boolean | `false` | Print the outcome as JSON |
| `--local` | boolean | `false` | Local-only VACUUM INTO backup (no compression or encryption) |

## Subcommands

| Command | Description |
| --- | --- |
| [`init`](init) | Set up encrypted state backup: install LFS, create recipients, verify round-trip |
| [`status`](status) | Show state backup health: last backup time, sizes, recipients |
