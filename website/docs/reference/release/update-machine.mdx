# rt release update-machine

`rt › release › update-machine`

Bring this machine's prod app, dev bundle, daemon, and served suite up to a released tag

## Usage

```bash
rt release update-machine [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--tag` | text |  | Released tag to update to; omit for the latest release |
| `--plan` | boolean | `false` | Print the resolved legs and exit without changing anything |
| `--verify-only` | boolean | `false` | Run only the final verification sweep |
| `--yes` | boolean | `false` | Skip every confirmation prompt |
| [`--json`](/guides/common-flags) | boolean | `false` | Emit the leg report as JSON |
