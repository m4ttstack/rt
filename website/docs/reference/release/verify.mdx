# rt release verify

`rt › release › verify`

Read-only confirmation that a tagged release actually published: the workflow run, notes, assets, draft state, and releases/latest

## Usage

```bash
rt release verify [<tag>] [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `<tag>` | text |  | Tag to verify; omit for the repo's latest v* tag |
| [`--json`](/guides/common-flags) | boolean | `false` | Emit the full report as JSON |
| `--no-wait` | boolean | `false` | Snapshot the workflow run once instead of polling it to completion |
