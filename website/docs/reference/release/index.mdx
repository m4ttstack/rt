# rt release

`rt › release`

Release-cycle checks for the rt repo itself

## Usage

```bash
rt release
```

## Subcommands

| Command | Description |
| --- | --- |
| [`preflight`](preflight) | Read-only report of every vendored layer's pin freshness, git/tag state, and the gate the pending diff implies |
| [`verify`](verify) | Read-only confirmation that a tagged release actually published: the workflow run, notes, assets, draft state, and releases/latest |
| [`update-machine`](update-machine) | Bring this machine's prod app, dev bundle, daemon, and served suite up to a released tag |
