# rt runner

`rt › runner`

Board of long-running commands in a detached tmux session (add, tail, restart, stop, focus)

## Usage

```bash
rt runner [flags]
```

## Arguments & flags

| Flag / Arg | Type | Default | Description |
| --- | --- | --- | --- |
| `--herdr` | boolean | `false` | Run commands in background herdr panes instead of tmux (needs the rt daemon) |
| `--seed-file` | text |  | Open the board pre-seeded from this file's &#123;"seed":[...]&#125; rows (the envelope `rt run --resolve-only` prints) instead of starting empty |
