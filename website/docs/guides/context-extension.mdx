# RT Context extension

The `rt-context` VS Code/Cursor extension shows your current worktree, branch, and linked Linear ticket in the status bar, so you always know which context you're in without running a command.

Setup installs it into every editor it detects (whether you install through mattstack.app's setup wizard or `rt --post-install`), so most people never need to think about it.

## Status bar

```
📁 main-worktree  │  🔖 ACME-1287: Add damage photo uploads
```

Clicking the item offers a short menu: open the linked Linear ticket, open the merge request, or reveal the worktree in Finder. Two more items sit beside it: **Worktrees** lists every worktree of the repo, and the branch item switches branches.

## Reinstalling or adding editors

```bash
rt settings extension
```

This opens a fuzzy picker to select which editors (Cursor, VS Code, Antigravity, and the like) to install into. Use it to reinstall after an editor update, or to add the extension to an editor you installed after setup.

See the full command reference: [`rt settings extension`](/reference/settings/extension).
