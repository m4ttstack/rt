# The menu bar app

mattstack.app is the macOS menu bar app that `rt` ships inside. It registers the daemon with launchd, shows its health at a glance, and delivers native notifications, so you don't need a terminal open to know something happened.

## The dot

| Dot | Meaning |
| --- | --- |
| Green | daemon running normally |
| Yellow | daemon starting |
| Orange | pending notifications, or a runaway process detected |
| Pink | daemon reachable but reporting a health problem |
| Red | daemon not reachable |
| Grey | state unknown (before the first status poll) |

## Menu actions

From the menu bar menu you can:

- open the mattstack window (Ctrl-Opt-Cmd-M)
- open **Processes…** or **Worktrees…**
- restart the daemon, or view its logs
- open **Settings…**
- toggle **Start at Login**
- check for updates
- quit

The **Processes…** panel's gear menu adds **Stop Daemon**, the crash log, setup status, and **Uninstall mattstack…**.

## Worktrees panel

**Worktrees…** lists the worktrees that were not cleaned up after their merge request merged or closed. The menu item shows how many there are, and once a day (from 09:00 local, when at least one tree needs a decision) a summary notification opens the panel when clicked.

Each row says why the tree is stuck and whether its work is safe somewhere else: already in the default branch, pushed to the remote, or patch-identical to what merged. It offers one guarded action: dispose, keep, push the branch, review the diff, stop the processes holding the tree, or remove it. Every action re-checks the tree before it runs. A removed tree goes to rt's 14-day trash rather than being deleted, and a tree holding the only copy of its work can only be forced after you confirm.

`rt worktree triage` prints the same rows in the terminal (`--json` for scripts). Files that match the `rt.worktrees.junk` globs, and `bun.lock` changes that only bump versions, do not count as dirty.

## Pane focus

When `rt pane focus` targets a pane, the app activates the terminal window hosting it. This works for both regular panes and daemon-hosted background panes.

## Window behavior

The app stays a regular Dock app for its entire run, so the Dock icon keeps its running indicator. Cmd-W closes the window (and cmd-M minimizes it). Quitting the app when no window is on screen is a real quit, whether from the Dock, Activity Monitor, or a script.

The app catalog is fetched at launch rather than on first window open. This means the first handoff or browser click opens the window without a catalog-fetch delay. The window holds its splash until deck answers and the app list has loaded, up to 90 seconds; a spinner appears beside the logo if that takes longer than the animation. If deck still has not answered, the splash shows "Can't reach deck" with the reason and a Retry button. A tab whose app answers with a server error shows the same kind of failure overlay, with Retry.

Cmd-F opens find in page inside the mattstack window.

Settings opens as a native tabbed window (General, Permissions, Fast Browser, Team, Uninstall); the titlebar names the active pane. The General tab's Developer section opens the other app (mattstack.app or mattstack-dev.app) after a confirmation; an app opened by hand takes the Mac over, so it retires and quits the current one.

## Updates

mattstack.app updates itself through Sparkle, which verifies the release signature, stages the install, and relaunches the app. It checks every 6 hours and downloads a new release on its own. When a release is ready, the menu item changes to **Update Available: &lt;version&gt;**; the update installs right away when none of the app's windows are open and setup isn't running, and otherwise when you quit the app.

**Check for Updates…** checks on demand, and `rt update` asks the running app to do the same, or points you at the latest release on GitHub when the app isn't running. The dev build (mattstack-dev.app) runs from source and never updates through Sparkle.

See also: the [daemon guide](/guides/daemon) for what the daemon itself does, and [`rt daemon`](/reference/daemon) / [`rt update`](/reference/update) in the command reference.
